## Santa Reserva — Sistema de Gestão Hoteleira

Projeto acadêmico desenvolvido em equipe durante o curso técnico em Informática do IFSC, utilizando Java, Java Swing e MySQL.

O sistema foi desenvolvido para auxiliar a gestão de estabelecimentos hoteleiros, contemplando funcionalidades como cadastro de hóspedes, gerenciamento de reservas de quartos, computadores e salas de reunião.

**Minhas contribuições**

* Desenvolvimento de interfaces gráficas utilizando Java Swing, com atenção à organização visual dos componentes e à experiência do usuário.
* Implementação de máscaras e formatação de campos para facilitar a entrada de informações.
* Desenvolvimento de classes DAO e métodos de persistência para integração das interfaces com o banco de dados.
* Colaboração em diferentes partes da aplicação, participando da integração entre as funcionalidades desenvolvidas pela equipe.

O projeto proporcionou minha primeira experiência prática mais abrangente com Java, especialmente na integração entre interfaces gráficas, regras de negócio e persistência de dados relacionais.
